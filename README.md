# News Explorer

News Explorer es una aplicación web full stack que permite a los usuarios buscar artículos de noticias por palabra clave y guardarlos en su perfil personal. Los resultados de búsqueda provienen de News API, y los artículos guardados se almacenan en una base de datos propia con autenticación de usuarios.

## ✨ Funcionalidades

- Búsqueda de artículos de noticias por palabra clave
- Registro e inicio de sesión de usuarios
- Guardar y eliminar artículos en el perfil personal
- Diseño responsivo para desktop, tablet y mobile
- Rutas protegidas para usuarios autorizados
